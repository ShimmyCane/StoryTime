📖 StoryTime — Code Map

Plain HTML/CSS/JS, no build step. index.html only holds the layout; each feature lives in its own small file so changes stay local.

How a story flows

members.jswho + level
→
dials.jsspin values
→
opening.jspick template
→
narrate.js / recorder.jstell + record
→
decisions.js / keywords.jsforks + tags
→
save.jsreview
→
db.jsdevice + Supabase
→
library.js / dashboard.js

All modules share two objects from js/state.js: App (members, current member, level, saved stories) and Story (the story being told). After a change a module calls Story.changed('transcript') etc.; others listen with Story.on(...).

Files

FileWhat it does
index.htmlPage layout: top bar, left play column (dials, story), right +/- panels (Forks, Keywords, Save, Library, Dashboard), gear drawer, modal, toast, error panel. Script load order at the bottom.
data/levels.jsDATALEVELS K → G6 with character targets, pinyin default, read-aloud speed. DEFAULT_LEVEL.
data/dials.jsDATADEFAULT_DIALS (Tone, Setting, Character) and EXTRA_DIALS (Time, Quest, Emotion, Weather). Option en values are the template tags.
data/templates.jsDATASTORY_TEMPLATES: 50 openings (zh + en + tags), weighted toward K.
data/stop_words.jsDATASTOP_WORDS ignored by the keyword cloud.
js/config.jsJSSupabase URL/key/timeout, DEFAULT_MEMBERS, PROMPT_WORDS (narration buttons), MAX_KEYWORDS, localStorage keys.
js/db.jsJSError log (_logError), shared family sign-in, members (Supabase → cache → defaults), per-member level, stories (device first, then Supabase sync).
js/state.jsJSApp, Story, newId, fmtDuration, escapeHtml.
js/ui.jsJSWeb Audio blips, toast, modal, gear drawer (sign-in, sounds, speech speed, show errors), bottom error panel.
js/members.jsJSMember chips + level dropdown; remembers each member's level.
js/dials.jsJSRender, spin (rolling animation), ◀ ▶ tweak, add/remove dials, custom dial form.
js/opening.jsJSScores templates: 2 × matching tags − level distance, random tie-break. Seeds transcript, sets name + tags. Pinyin (pinyin-pro) and English toggles.
js/narrate.jsJSPrompt buttons insert at cursor, transcript editing, zh-CN read-aloud (speed by level).
js/recorder.jsJSMediaRecorder, timer, playback, Share (share sheet) with Download fallback. Audio is not uploaded.
js/decisions.jsJS2-choice / 3-choice / slider forks; choice logged to decisions[] and the transcript.
js/keywords.jsJSWord counts via Intl.Segmenter (fallback: repeated 2-char pairs); tag cloud; pick up to 4.
js/save.jsJSReview panel and Save.
js/library.jsJSSaved stories (mine / all family), open, read aloud, export JSON, delete.
js/dashboard.jsJSStory count, time told, forks, top keywords, "next time try" hints.
js/app.jsJSStartup order; loads device data first, then Supabase.
css/*.cssCSSbase (pastel tokens in :root, two-column layout, buttons, panels, gear), dials, narrate, library.
supabase/schema.sqlSQLstorytime_stories, storytime_member_settings; RLS for the signed-in family login.
